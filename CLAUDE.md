# CLAUDE.md — Catholic Bible Study App

**Always read this file first. Then open the patch file you are working on.**

---

## What this is

A personal, static web app for studying the Catholic Bible. It runs entirely in the browser and deploys to GitHub Pages with no build step. The user reads the **Douay-Rheims Bible** (public-domain, full 73-book Catholic canon including the deuterocanon), bundled locally as static JSON in `data/bible/` — no external Bible API or API key is required to read Scripture. Polish support was removed; the app is English-only. (API.Bible was tried first, per the original patch plan, but its free tier offers no Catholic translation — no deuterocanon and no NABRE/Douay-Rheims — so the reader was switched to bundled local text instead.)

---

## Non-negotiable rules

1. **No build step.** No npm run build, no Webpack, no bundler. Everything deploys as-is to GitHub Pages.
2. **CDN only for external libraries.** Only these hosts are permitted: `cdnjs.cloudflare.com`, `fonts.googleapis.com`, `fonts.gstatic.com`.
3. **No non-Catholic AI.** The only AI service this app may call is Magisterium AI (`magisteriummagi.ai`). Never call OpenAI, Anthropic, Google AI, or any general-purpose LLM.
4. **Vanilla JS + ES modules.** No React, no Vue, no Alpine. Plain JavaScript with `type="module"` imports.
5. **One patch at a time.** Implement one patch fully and confirm it works before touching the next. Do not skip ahead or combine patches.
6. **Do not touch files outside the current patch's scope.** If a patch says "modify `bible.js`", do not also change `map.js`.

## Global state shape (js/app.js)

All modules share this object. Define it in `app.js` and import it where needed.

```js
export const state = {
  book: 'JHN',          // current book (matches data/bible/<ID>.json filenames)
  chapter: 1,           // current chapter number
  selectedVerseId: null, // e.g. "JHN.1.1"
  selectedVerseText: '', // plain text of selected verse
  activeTab: 'footnotes',   // 'footnotes' | 'xref' | 'ccc' | 'map' | 'ai'
  mapInitialised: false,
};
```
